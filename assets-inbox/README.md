# Assets inbox

Drop client assets here. This folder is NOT deployed (it is outside `public/`).

- `logo/` – logo files (SVG or transparent PNG; coloured + white versions if they exist)
- `photos/` – product / project photos (note which ones the client has approved for use)
- `other/` – brand guide, price lists, copy documents, anything else

Anything used on the site gets optimised and moved into `public/` (or Cloudinary) by Claude.
